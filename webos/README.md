# Zephyr TV Receiver for webOS

What's here: webOS's own files of Zephyr TV Receiver (`app/`: `appinfo.json` and its icons) and its service
(`service/`: the proxy that adds a stream's headers). The web app itself is shared with VIDAA, in
`site/public/receiver/`; `package.sh` puts them together into the .ipk.

How to install it, and what it does: [docs/receiver.md](../docs/receiver.md).
